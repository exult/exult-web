• 2026-10-24

    Seven Towers has finally had a long-overdue update. With SourceForge retiring PHP hosting, I have converted the site to static pages. The pages and documentation downloads are now generated from the same sources, which can also be built locally.

    The Usecode reference and tutorials now have syntax highlighting based on my VS Code extension, along with downloadable Markdown and Natural Docs versions. The Markdown intrinsic reference uses text instead of images for its game indicators, so it is easier to move around.

    Reworked the navigation and download pages, added section tabs and an icon preview gallery, and added a layout for phones and other small screens. The gold page titles are now text instead of images; use the “Use readable titles” checkbox if you prefer a plain font. Your browser remembers this preference across pages.

    Also improved contrast, keyboard navigation, and screen-reader support. Links and selected sections have cues that do not depend on color, and both light and dark themes are checked automatically before deployment.
