To the right of many intrinsic 'prototypes', you can see an indicator between square brackets. This indicator is a quick way to see if that intrinsic is available for the specific game you are interested in. The possible values of these indicators are:

| Indicator | Meaning |
| --- | --- |
| ![[BG]](images/bgsm.png) | BG-specific intrinsic |
| ![[SI]](images/sism.png) | SI-specific intrinsic |
| ![[Exult]](images/exultsm.png) | Exult-specific intrinsic, available to both BG and SI |
| ![[BG, Exult]](images/bgexultsm.png) | Originally BG-only, Exult allows it in SI too |
| ![[SI, Exult]](images/siexultsm.png) | Originally SI-only, Exult allows it in BG too |
| ![[Exult: BG]](images/exultbgsm.png) | Exult-specific intrinsic, available only to BG |
| ![[Exult: SI]](images/exultsism.png) | Exult-specific intrinsic, available only to SI |
| (not present) | Intrinsic available for BG and SI |

The '![[Exult]](images/exultsm.png)', '![[BG, Exult]](images/bgexultsm.png)' and '![[SI, Exult]](images/siexultsm.png)' indicators are essentially equivalent to no indicator at all; they are used in this document only for completeness.
