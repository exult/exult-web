Plays scripted animated and/or text cutscene after checking whether the files text_info.txt and text.flx exist in the patch folder.

#### Parameters

| Parameter / value | Description |
| --- | --- |
| `text` | The base name of the cutscene files. |
| `fade_out` | This optional parameter controls whether the game fades out to the scene; defaults to `true`. |
| `fade_in` | This optional parameter controls whether the the scene fades in to the game; defaults to `true`. |
