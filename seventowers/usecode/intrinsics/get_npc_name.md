Gets the name of one or more objects. Despite the name, this intrinsic can be called for any object, not just NPCs; for non-NPCs, the return is the text displayed when you click the object.

#### Parameters

| Parameter / value | Description |
| --- | --- |
| `obj` | The object, or array of objects, whose names are desired. |

#### Return

If the input is an array of objects, the return is an array with the names of these objects. The output array places the object names in the same order as the objects are in the input array.

Otherwise, the return is the name of the given object.
